# web-extension-options demo

An example Web Extension demonstrating [web-extension-options](https://github.com/fent/web-extension-options).

View the live demo at [fent.github.io/web-extension-options](https://fent.github.io/web-extension-options/).

## Running as an Unpacked Extension

1. Clone or download this branch.
2. Open Chrome or Firefox and navigate to `chrome://extensions` or `about:debugging`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** (or **Load Temporary Add-on**) and select this directory.
5. Click **Details** -> **Extension options** to open the options page.
